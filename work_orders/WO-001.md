# 실제 채용공고 데이터 연결

## 목표
화면의 수요 표와 추천이 합성 데이터가 아니라 실제 IT 채용공고에서 나오고, 합성 경고가 사라진다.

## 범위
- 출처 판단은 [[D-004]]: 사람인 API(규모, 키워드) + Greenhouse/Lever 공개 API(본문 근거 문장), Techmap은 가격 확인 후
- 출처별 어댑터를 `data/real/jobs.json`(현재 `postings` 형식 + `source`, `collected_at`, `evidence_level`)으로 변환
- 수집 검사: 필수 필드(자격요건 원문·출처 URL), 중복 ID, 개인정보 패턴(전화번호·이메일), 마감 여부, 수집일 manifest
- 한 직무(예: 백엔드) 30건 내외 소량으로 먼저 끝까지 연결
- 공고 원문·출처 URL·수집 시각 보존. 원문은 git에 올리지 않음 (`data/real/`)

## 제외
- 대량 수집, 자동 수집 스케줄, AWS 배포, Bedrock 호출
- 교육 데이터 교체 (별도 작업지시서)

## 완료 조건 (사용자 관점 문장 + 확인 방법)
- [ ] 화면에서 실제 공고 기준 수요 표가 보이고 합성 경고가 나오지 않는다 → `run.json`의 `synthetic: false`
- [ ] 수요 표의 모든 기술이 근거 문장을 가지고, 근거를 누르면 실제 공고 원문 문장과 출처로 이어진다 → 근거 문장 원문 포함 테스트
- [ ] 사전에 없는 기술·불확실 건수가 숫자로 보인다 → 검증 현황 섹션
- [ ] 사람이 정답을 단 공고 10건으로 사전 추출의 정밀도·재현율이 나온다 → `python -m eval.evaluate --gold eval/gold.real.json`

## 중단하고 보고할 조건
- 출처의 이용 범위가 불명확함
- 원문에 자격요건/우대사항 구분이 없어 현재 형식으로 바꿀 수 없음
- 개인정보(담당자 연락처 등)가 원문에 섞여 있음
