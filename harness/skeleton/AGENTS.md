## 세션 시작
1. 이 파일 → `docs/progress.md` → 진행 중인 `work_orders/WO-*.md` 순서로 읽는다.
2. 작업 전 관련 코드를 검색해 이미 있는 기능인지 확인한다.

## 반드시 지킬 것
- **AI가 제안하고, 코드가 검증하고, 사람이 승인한다.** AI의 완료 선언은 승인이 아니다.
- 완료 보고 전 `python harness/check.py`를 실행하고 결과를 그대로 보고한다. 통과해도 작업지시서의 사용자 관점 완료 조건을 따로 확인한다.
- 결과 목록을 줄이면 생략 건수를 표시하거나 전체를 보여준다.
- 유료 API·클라우드 리소스·외부 데이터 수집은 사용자 승인 후에만 한다.
- `.env`, 키, 토큰을 출력·문서화·커밋하지 않는다.
- (프로젝트 고유 규칙)
