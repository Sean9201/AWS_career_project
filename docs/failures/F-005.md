# Techmap 호출이 초당 1회 제한(429)에 걸림

## 증상
건수 조회 2회 뒤 검색 명령을 바로 실행하자 HTTP 429 "rate limit per second". 실패한 요청도 사용량(유료 가능)에 잡혔다.

## 원인
`skillpath/sources/techmap.py`가 요청 간격을 프로세스 메모리에만 기억했다. 명령을 연달아 실행하면 새 프로세스는 직전 요청 시각을 몰라 1초 안에 호출했다.

## 수정
마지막 요청 시각을 사용량 파일(`data/real/techmap/usage.json`)에 함께 저장하고, 새 프로세스도 그 시각을 읽어 1.1초 간격을 지킨다.

## 재발 방지
- 회귀 테스트: `test_spacing_holds_across_separate_runs`
- 같은 작업 중 `--pages 3`이 1페이지부터 다시 받아 요청 1회를 낭비했다. `--start-page` 옵션을 추가했다. (비용 0, 사용량 7/80)
