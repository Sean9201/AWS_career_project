# 대화체 제목 공고에서 자격요건이 "주요업무"로 분류됨

## 증상
실제 공고 화면의 MySQL 근거에서 현대오토에버 공고의 자격 요건 목록이 "주요업무, 업무"로 표시됐다. 여러 항목이 한 줄로 붙어 근거 문장도 지나치게 길었다.

## 원인
`skillpath/segment.py`의 제목 사전이 "자격요건/우대사항" 같은 명사형만 알았다. "이런 분과 함께 하고 싶어요 / 이런 분이라면 더욱 좋아요" 같은 대화체 제목을 못 찾아, 앞의 "합류하시면 함께 할 업무예요" 섹션이 계속 이어졌다. 목록이 `A - B - C`로 한 줄에 펼쳐진 형식도 가정하지 않았다.

## 수정
- 대화체 제목(자격·우대·절차·근무지·참고)을 제목 사전에 추가.
- 한 줄에 ` - `가 2번 이상이면 항목으로 나눔. 1번은 "2 - 3년" 같은 범위일 수 있어 그대로 둠.

## 재발 방지
- 회귀 테스트: `test_conversational_headings_do_not_fall_under_previous_section`, `test_single_dash_range_is_not_split`
- 같은 유형이 또 나오면: 섹션이 바뀌지 않은 채 "업무" 섹션에 "경험/역량/이해" 같은 자격 표현이 몰리는 경우를 check로 경고하는 방안 검토.
