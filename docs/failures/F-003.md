# 템플릿 저장소에서 옵시디언 기본 설정이 커밋되지 않음

## 증상
ai-harness 0.2.0을 GitHub에 올렸는데 `harness/skeleton/.obsidian/`의 설치용 설정 파일이 빠져 있었다. 템플릿으로 새 프로젝트를 만들면 옵시디언 템플릿 폴더 연결이 설치되지 않는다. 0.2.1 작업 중 `git status`에 새 파일이 안 보여 발견했다.

## 원인
ai-harness의 `.gitignore`에 있던 `.obsidian/`이 루트뿐 아니라 모든 하위 경로의 `.obsidian/`과 일치했다. 로컬 테스트는 작업 폴더의 파일을 읽어서 통과했고, 저장소에 실제로 들어간 파일은 확인하지 않았다.

## 수정
ignore 규칙을 루트 고정 `/.obsidian/`으로 바꾸고 빠진 파일을 커밋.

## 재발 방지
- 회귀 테스트: `test_fresh_project_gets_full_setup_that_passes_lint` — 설치 결과에 `.obsidian/templates.json`이 있어야 한다. 로컬이 아니라 **저장소를 새로 받은 CI**에서 실행돼야 이 실패를 잡는다 (ai-harness의 GitHub Actions).
- 같은 `env-config` 유형이 다시 나오면 "템플릿에 넣을 파일은 ignore 규칙을 루트 고정으로 쓴다"를 규칙 후보로 등록.
