# "A 또는 B" 선수지식인데 A가 있어도 B를 먼저 필요하다고 안내함

## 증상
보유 기술에 Java를 넣어도 Kafka 과정(선수지식 "Java 또는 Python 기초")에 "먼저 필요한 기술: Python"이 표시된다.

## 원인
`skillpath/recommend.py`가 선수지식 문장에서 찾은 기술을 모두 AND로 취급한다. "또는/or"의 OR 관계를 보지 않는다.

## 수정
(미정) 후보: 선수지식 문장에 "또는|or|/"가 있으면 그 묶음 중 하나라도 보유하면 충족으로 처리. 판단할 수 없는 문장은 안내 문구를 "선수지식을 확인하세요"로 두고 기술을 단정하지 않음.
