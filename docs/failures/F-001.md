# 부족 기술 추천이 상위 5개에서 잘려 Go가 사라짐

## 증상
수요 표에는 "Go 근거 1건"이 있는데, "나에게 부족한 기술"에는 Go가 없었다. 사용자가 화면에서 발견했다.

## 원인
`skillpath/recommend.py`의 `recommend(..., limit=5)`가 부족 기술을 5개만 반환하고 나머지를 표시 없이 버렸다. 백엔드 기준 Go는 22개 중 7번째. 수요 섹션은 근거를 8개까지만 펼쳐서 섹션마다 목록 길이도 달랐다.

## 수정
- 제한을 없애고 모든 부족 기술을 반환. 과정이 없는 기술은 "확인된 과정 없음"으로 표시.
- 수요 표에 `내 상태`, `확인된 과정` 열을 추가해 세 섹션을 같은 목록으로 연결.
