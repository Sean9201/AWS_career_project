# 근거 목록이 "구분 없음"이라는 내부 용어를 노출하고, 한 공고가 여러 줄로 보여 중복처럼 읽힘

## 증상
근거 문장 보기에서 "(구분 없음, 필수)", "(구분 없음, 구분 없음)" 같은 표기가 나와 사용자가 뜻을 알 수 없었다. 같은 공고(루트빛, 마린소프트)가 문장마다 한 줄씩 2~3번 나와, 중복 집계가 안 된 것인지 근거가 두 번 뜬 것인지 구분되지 않았다. 사용자가 화면에서 발견했다.

## 원인
- `app.py`가 코드 내부 값(섹션 `unknown` → "구분 없음", 판정 `unknown` → "구분 없음")을 그대로 보여줬다. 섹션과 판정이라는 두 축을 사람에게 설명 없이 나란히 붙였다.
- 근거를 문장(claim) 단위로 나열했다. 집계는 공고당 1번이지만 화면은 그렇게 보이지 않았다. 확인 결과 두 줄은 같은 URL의 다른 문장이었고 중복 집계는 아니었다.

## 수정
`skillpath/present.py` 추가.
- 공고 단위로 묶어 **공고마다 판정 한 줄**(필수/우대/업무/언급만, 집계와 같은 기준 = 가장 강한 문장)을 보여주고, 그 아래에 문장과 **판정 이유**를 붙인다. 예: "필수 · 자격요건 섹션", "필수 · 섹션 제목은 없지만 문장에 '필수' 표기", "언급만 · 제목·소개 등에 등장, 필수/우대 판단 안 함".
- 표의 "구분 없음" 열을 "언급만"으로 바꾸고 설명문을 고쳤다.
