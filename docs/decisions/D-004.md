# IT 채용공고 데이터 출처: 합법적인 공식 경로를 조합한다

## 배경
기술 수요를 근거 있게 보여주려면 두 가지가 필요하다.
- **규모**: 직무·지역별로 몇 건이 그 기술을 요구하는가
- **근거 문장**: 자격요건·우대사항 원문 (필수/우대 구분, "왜 필요한지"의 증거)

한 출처가 둘 다 주는 경우가 드물다. 2026-11-05 공식 문서·robots.txt를 직접 확인한 결과다.

## 결정 (제안, 2026-11-05 GPT 검토 반영)
1. **Techmap 무료 구간 = 분석 데이터 후보 1순위.** 본문이 있어 같은 공고 집합에서 규모와 근거 문장을 함께 얻을 수 있다. 먼저 건수 조회 → 100~200건 표본으로 한국어 비율·중복률·본문 존재율·원 출처 분포를 측정하고 통과하면 확대. 요청 상한과 비용 알림을 먼저 건다. `countryCode` 필터와 응답 필드명은 첫 호출로 확인한다(가격 페이지에는 국가 필터 언급 없음).
2. **고용24 = 학교(부경대) 경유 승인 문의.** 승인되면 직무내용·우대조건이 있는 국내 공고라 가장 좋다. 일정이 불확실하므로 다른 작업을 막지 않는다.
3. **사람인 API = 규모 보조지표.** 근거 수준 `tag`, "언급"으로만 집계.
4. **Greenhouse/Lever = 추출기 검증용 추가 사례.**
5. **출처끼리 건수를 합산하지 않는다.** 비율의 분자와 분모는 같은 데이터셋·직무·지역·기간에서만 계산한다.
6. **실시간 수집은 하지 않는다.** 수집일을 명시한 고정 스냅샷으로 평가 재현성을 확보하고, 주기 수집은 EventBridge → Lambda → S3 구조로 소량만 시연한다.
7. 결과 표기는 "대한민국 전체 수요"가 아니라 "수집된 국내 IT 공고 N건(출처, 기간) 기준"으로 한다.

## 영향
- 데이터에 `source`, `collected_at`, `evidence_level`(sentence/tag)을 필수로 기록.
- 원문은 `data/real/`에만 두고 git에 올리지 않는다.
- 외부 API 호출은 출처별로 사용자 승인 후 시작한다.
