# 사전에 없는 기술은 자동으로 합치지 않는다

## 배경
대회 자료는 표현 표준화에 임베딩을 예시로 든다. 하지만 유사한 문서를 찾았다고 같은 기술이라는 보장은 없다.

## 선택지와 이유
- 임베딩 유사도로 자동 병합: 빠르지만 Java/JavaScript 같은 오병합 위험
- **선택: 사전(표준명+별칭)으로 확정하고, 사전에 없는 기술은 불확실로 남긴다.** 임베딩은 이후 "가까운 표준명 후보 제시"에만 쓰고 확정은 사람이 사전에 추가하는 방식으로 한다.

## 영향
- 불확실 건수가 화면과 집계에 따로 보인다.
- 사전 추가 이력이 곧 표준화 근거가 된다.
