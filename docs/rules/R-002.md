# 완료는 check 통과와 사용자 관점 완료 조건으로 판단한다

## 왜 필요한가
[[F-002]]: 구현자의 테스트 통과만으로 완료를 보고해 사용자 관점 누락을 놓쳤다.

## 어떻게 강제하는가
check. 진행 중(`active`) 작업지시서는 `verify` 명령과 "완료 조건" 절이 있어야 하며, 없으면 `harness/check.py`가 실패한다. 다음 단계로 Claude Code 작업 종료 훅에서 check를 자동 실행하는 구조 강제를 검토한다.

## 효과
도입 2026-11-05. 프로젝트 무관 규칙이므로 두 번째 프로젝트에서 같은 방식으로 쓰이면 승격 후보.
