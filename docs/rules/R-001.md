# 결과 목록을 줄일 때는 생략 건수를 표시하거나 전체를 보여준다

## 왜 필요한가
[[F-001]]: 추천을 5개로 자르면서 생략 사실을 숨겨, 수요 표와 추천이 연결되지 않아 보였다.

## 어떻게 강제하는가
문장. 어떤 목록이 "줄여도 되는 목록"인지는 코드만으로 판단하기 어려워 일반 check로 강제하지 못한다. 프로젝트 안에서는 해당 기능마다 "전체가 나온다" 회귀 테스트로 막는다.

## 효과
도입 2026-11-05. `silent-drop` 재발 시 승격 검토, 혹은 공통 목록 함수(생략 건수 반환을 강제하는 구조)로 강화.
