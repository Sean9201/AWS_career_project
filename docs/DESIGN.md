# 설계 원칙과 단계별 계약

## 원칙: 입력은 유연하게, 출력은 엄격하게

규칙으로 모든 표현을 미리 잡으려 하면 깨지고, 모델에 전부 맡기면 결과를 설명할 수 없습니다. 그래서 역할을 이렇게 나눕니다.

- **AI(Bedrock)**: 표현이 제각각인 공고 문장을 읽고 기술·근거 문장·필수/우대를 *제안*합니다.
- **코드**: 제안을 원문과 대조해 *검증*하고, 개수·비율을 *계산*하고, 추천 이유를 저장된 근거로 *조립*합니다.

모델이 무엇을 내놓든 원문에서 추적되지 않으면 집계와 추천에 쓰지 않습니다.

## 단계별 입력·출력·검증

### ① 추출 — `Claim`

| 필드 | 의미 |
|---|---|
| `posting_id`, `section` | 공고와 섹션(`qualifications` 자격요건 / `preferred` 우대사항) |
| `skill` | 추출기가 쓴 기술명 그대로 |
| `evidence` | 추출기가 읽었다고 주장하는 원문 한 줄 |
| `requirement` | `required` / `preferred` |
| `extractor` | `rules` / `bedrock` |

- `rules`: `data/skills.json` 사전으로 문장마다 기술명을 찾습니다. 호출 비용이 없고 재현 가능하며, Bedrock의 비교 기준(베이스라인) 역할을 합니다.
- `bedrock`: 구조화 출력(`messages.parse`)으로 같은 형식을 받습니다. 거절이나 잘린 응답은 빈 결과가 아니라 실패로 처리합니다.

### ② 검증 — `VerifiedClaim.status`

| 상태 | 조건 |
|---|---|
| 확인 | 근거 문장이 해당 섹션 원문에 있음 + 기술이 사전으로 표준화됨 + 그 기술이 근거 문장에 실제로 있음 + 필수/우대가 원문 판정과 일치 |
| 불확실 | 근거는 원문에 있으나, 사전에 없는 기술 / 근거 문장에 그 기술이 없음 / 필수·우대 판정 충돌 |
| 제외 | 근거 문장이 원문에서 발견되지 않음 (공백 차이는 허용) |

필수/우대 원문 판정: 우대사항 섹션은 우대입니다. 자격요건 섹션이라도 문장에 '우대·선호·있으면 좋' 등이 있으면 우대입니다.

### 표준화 규칙

- 사전의 표준명과 별칭이 같은 기술입니다 (`아마존 웹 서비스` = `AWS`, `쿠버네티스` = `Kubernetes`).
- 영문자 경계를 검사합니다. `Java`는 `JavaScript` 안에서 매칭되지 않습니다. 한글 조사는 허용합니다 (`Python을`).
- 겹치는 표기는 가장 긴 것을 택합니다 (`Spring Boot` > `Spring`, `MySQL` > `SQL`).
- 사전에 없는 기술은 자동으로 합치지 않고 불확실로 남깁니다. 이후 임베딩 유사도는 *후보 제시*에만 쓰고 확정은 사람이 합니다.

### ③ 집계 — `demand.json`

- 단위는 공고 수입니다. 한 공고에서 여러 번 언급돼도 1건입니다.
- 한 공고가 같은 기술을 필수와 우대로 모두 언급하면 필수로 셉니다.
- 확인된 근거만 셉니다. 불확실은 `uncertain_n`으로 따로 보여줍니다.

### ④ 추천

- 부족 기술 = 목표 직무에서 요구된 기술 − 사용자가 입력한 기술. 필수 건수 순으로 정렬합니다.
- 과정이 그 기술을 *다룬다*는 근거는 과정의 커리큘럼 → 소개 → 과정명 순으로 찾습니다. **선수지식은 근거로 쓰지 않습니다** (Java가 선수지식인 과정은 Java를 가르치는 과정이 아닙니다).
- 선수지식에 있는 기술 중 사용자에게 없는 것은 '먼저 필요한 기술'로 안내합니다.
- 근거가 없으면 추천하지 않고, 확인된 과정이 없다고 표시합니다.

## 평가

`eval/evaluate.py`는 확인된 추출 결과를 사람 정답과 비교합니다.

- `skill`: (공고, 기술)을 찾았는가 → precision / recall / F1
- `labeled`: (공고, 기술, 필수/우대)까지 맞았는가
- 상태별 건수, 놓친 항목, 정답에 없는 항목

정답은 실제 공고 원문을 사람이 직접 보고 만들어야 합니다. 합성 데이터 점수는 동작 확인일 뿐 정확도 근거가 아닙니다.
